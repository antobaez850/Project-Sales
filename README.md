# Project Sales

<b>Objetivo principal:</b> medir la performance de las ventas y los productos.
Para eso se desarrollo un dashboard con los siguientes indicadores y dimensiones:

* Sales Overview: ventas totales y ticket promedio (ARS/USD separados), evolución mensual (cantidad + monto), ventas por país, ranking de productos, % de compradores con más de un producto.
* Sales Detail: precio promedio por tipo de producto, % de planes con cuotas pendientes (excluyendo contado), distribución de ventas según cantidad de cuotas pendientes, con filtros por producto, vertical y país.
